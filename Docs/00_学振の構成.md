# 学振

## 研究計画

### （1）研究の概要及び研究の位置づけ（1項まで）

- 研究課題名
  - 科学実践における時空間的制約　－大学教員を事例にー
- 研究の概要（全角500字程度）
- 研究の位置づけ
  - 当該分野の状況
  - 当該分野の課題
  - 本研究計画の着想に行った経緯

### （2）研究目的・内容等（2項まで）

- 研究目的
- 研究方法
- 研究内容
- 計画の概要
  - 何をどこまで明らかにするのか？
  - 上手くいかなかったら？
- 研究のインパクト（アクチュアリティ）
  - 特色
  - 独創的な点
  - 予想されるインパクト
- 研究計画が所属研究室としての研究活動の⼀部と位置づけられる場合は申請者が担当する部分を明らかにしてください。
  - 該当なし
- 研究計画の期間中に受⼊研究機関と異なる研究機関（外国の研究機関等を含む。）において研究に従事することも計画している場合は、具体的に記⼊してください。
  - 該当なし

- それ以外の活動
- 上記内容から分析
- 今後、自分が必要だと思う要素
