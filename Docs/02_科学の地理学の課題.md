# 科学の地理学の課題

主な課題は4点である。一つ目は、研究とその事例の多くは欧米中心であること。二つ目は、歴史地理学の偏重である。三つ目は、日常性が欠如している点である。四つ目は、地理学的視点が不足しているという点である。
一つ目の課題は科学の地理学の主要概念であるローカルな知識を理解する上でも、研究が欧米中心に偏ってはならない。Meusburger et.al.（2010）においても指摘されており、アフリカでの実践やアメリカ先住民族の知識についての事例を紹介している。こうした非欧米圏における知見を増やすことは、欧米との比較などが可能となるため、科学の地理学における議論の拡大に繋がる。
二つ目の課題である歴史地理学の偏重というのは、Powell（2007a）でも指摘している点である。科学の地理学の成立をみると、提唱者であるリヴィングストンが歴史地理学の専門であっただけでなく、SSKからの流れを汲んでいることが明らかとなった。それゆえ、歴史事例からのアプローチが多いが、こうしたアプローチは従来SSKが受けてきた批判を同様に受けることになる。代表的なものとして、分析する社会学者が科学者個人の欲求や関心を所属していた階級や社会集団によって説明するため，資料のつなぎ方次第で社会的影響の強弱を決められる点が挙げられる（松本 2021：41）．そのため、歴史地理学だけでなく、様々なアプローチを模索する必要がある。
三つ目の課題は現代のローカルな科学を捉える上で必要な観点である。二つ目の課題で挙げたような歴史的な時間軸の研究やPowell（2007b）に代表されるような極地環境など非日常的な事例が依然として多い。また、近年において科学と政治というスケールの大きい研究も見受けられる。その一方で、科学を生活の一部として捉え、科学者が日常生活をどのように過ごしているのか、日常生活の中で科学実践がどう埋め込まれているのかといった研究は管見する限り見られなかった。しかし、研究者の経験や生活世界に注目することは知識の形成過程を理解する上で不可欠な要素である（Barnes 2008）。
四つ目の課題の要因は、科学の地理学が科学論における空間論的転回の範疇を出ていないことにある。一定の基礎概念を持ちつつも、やはり社会構築主義やアクターネットワーク理論など科学社会学などの枠組みに依存している。こうした枠組みは有用である一方、従来の科学論の結果と類似してしまう。そのため、科学論から空間を考えるだけでなく、地理学から科学を考えることで科学の地理学という独自の視点が強化されるだろう。
